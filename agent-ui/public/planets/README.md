# Planet Images for Roadmap

Place high-quality planet images in this directory. You can download free planet images from NASA or use generated planet textures.

## Required Planet Images:

1. **earth.png** - Q1 2026 (Completed milestone)
2. **mars.png** - Q2 2026
3. **jupiter.png** - Q3 2026
4. **saturn.png** - Q4 2026
5. **uranus.png** - Q1 2027
6. **neptune.png** - Q2 2027
7. **pluto.png** - Q3 2027
8. **star.png** - Q4 2027 (for Alpha Centauri)

## Recommended Sources:

### Free NASA Images
- https://solarsystem.nasa.gov/resources/
- https://images.nasa.gov/

### Free Planet Textures
- https://www.solarsystemscope.com/textures/
- Download high-res planet textures (2K or 4K)

### AI Generated
- Use Midjourney/DALL-E with prompts like:
  - "realistic Mars planet texture, space photography"
  - "detailed Jupiter planet with great red spot"
  - "Saturn with rings, realistic space photo"

## Image Specifications:

- **Format**: PNG or JPG
- **Size**: 512x512 to 1024x1024 pixels (square)
- **Background**: Transparent PNG preferred (or black background)
- **Quality**: High resolution for crisp display

## Quick Setup:

```bash
# Download or generate 8 planet images
# Rename them to match the filenames above
# Copy to this directory:
cp /path/to/your/planets/*.png /Users/igorkudinov/Ton_agent/landing-page/public/planets/
```
