# Landing Page Images

Place your screenshot images in this directory:

## Required Images:

### 1. chat-demo.png
- **Description**: Screenshot of the Esprito AI chat interface showing a swap interaction
- **Recommended size**: 1920x1080 or similar 16:9 aspect ratio
- **Source**: Take a screenshot from http://localhost:5173 showing the full chat conversation

### 2. tonviewer-demo.png
- **Description**: Screenshot of a verified transaction on Tonviewer
- **Recommended size**: 1200x800 or similar
- **Source**: Screenshot from tonviewer.com showing a confirmed swap transaction

### 3. space-asteroid.jpg (Optional)
- **Description**: Space/asteroid background image for the Tonviewer section
- **Recommended size**: 1920x1080
- **Source**: Any high-quality space photograph or use the asteroid image you provided

## How to Add Images:

1. Copy your screenshots to this directory:
   ```
   landing-page/public/images/
   ```

2. Rename them to match the filenames above

3. The landing page will automatically load them

## Temporary Placeholder:

If images are missing, the page will show:
- A gradient background for the hero section
- Placeholder areas for screenshots
- The layout will remain intact

## Screenshot Tips:

- Use high resolution (at least 1920x1080 for main screenshots)
- Capture the full interface with dark theme enabled
- For chat-demo: Show a complete swap conversation with confirmation
- For tonviewer-demo: Show the transaction tree view with "Confirmed transaction" status
